IA Bajo Control — Proyecto Intermodular de Sergio Ruiz y David Clemente
Enlace al repositorio en GitHub: https://github.com/SergioRuizm/ia_bajo_control.git
Contenido de la entrega
La entrega está formada por dos elementos:
1. Documento principal en PDF
   06_2DAW_DAW_1Ev_IA_Bajo_Control.pdf
   Contiene la memoria del proyecto: análisis del encargo, planificación y experimentación, comparación de las herramientas de IA, validación técnica, plantillas reutilizables, conclusiones y referencias.
2. Archivo comprimido de evidencias
   06_2DAW_DAW_1Ev_IA_Bajo_Control_EVIDENCIAS.zip
   Contiene el material complementario de evidencias asociado a los casos identificados como P01–P08, incluidas las pruebas, respuestas e iteraciones recogidas en el documento de evidencias.

Instrucciones de uso
1. Consultar la memoria principal
1. Descarga o guarda el archivo 06_2DAW_DAW_1Ev_IA_Bajo_Control.pdf.
2. Ábrelo con cualquier lector de PDF.
3. Utiliza el índice para acceder a los apartados del proyecto.
4. Cuando un apartado remita al documento de evidencias, consulta el ZIP indicado en el siguiente paso.
2. Consultar las evidencias
1. Guarda 06_2DAW_DAW_1Ev_IA_Bajo_Control_EVIDENCIAS.zip en tu equipo.
2. Haz clic derecho sobre el archivo y selecciona Extraer, Descomprimir o una opción equivalente.
3. Abre la carpeta resultante.
4. Localiza las evidencias mediante sus códigos P01–P08 y consulta el material correspondiente al caso que necesites revisar.
3. Relacionar ambos documentos
Los códigos P01–P08 sirven para localizar las evidencias y relacionarlas con los ocho casos descritos en la memoria principal. Para seguir el trabajo, se recomienda abrir primero el PDF y utilizar el ZIP como material de consulta complementario.
Orden recomendado
1. Leer el PDF principal para conocer el contexto, los objetivos y la organización del proyecto.
2. Consultar en el ZIP las evidencias P01–P08 cuando se necesite comprobar una ejecución, respuesta o iteración.
3. Volver a la memoria para revisar la valoración, la validación técnica y las conclusiones asociadas.
Notas
- Mantén juntos el PDF y el ZIP para conservar la relación entre la memoria y sus evidencias.
- No renombres los códigos P01–P08 de las evidencias, ya que se utilizan como referencias dentro del proyecto.
- Esta entrega es documental: los archivos se consultan, no se ejecutan como una aplicación.
